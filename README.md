# 🧠 Perplexity Clone (Flutter)

A modern **Perplexity AI-inspired question answering application** built
using **Flutter & Dart**.\
This project replicates the core functionality and clean UI experience
of Perplexity in a fully cross-platform Flutter environment.

------------------------------------------------------------------------

## 🚀 Features

-   💬 AI-based question answering\
-   ⚡ Fast and smooth response rendering\
-   🎨 Clean & minimal UI design\
-   🌙 Dark mode support\
-   📱 Cross-platform support:
    -   Android\
    -   iOS\
    -   Web\
    -   Windows\
    -   macOS\
    -   Linux\
-   🧩 Modular and scalable architecture

## ⚙️ Getting Started

### 1️⃣ Clone the Repository

git clone https://github.com/ahr1223/perplexity-flutter.git\
cd perplexity

### 2️⃣ Install Dependencies

flutter pub get

### 3️⃣ Run the Application

flutter run

For Web: flutter run -d chrome

For Windows: flutter run -d windows
